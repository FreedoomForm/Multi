    45→### SHMQ Paper — Technical Specification
    46→
    47→**Key Equations:**
    48→
    49→| Eq | Description | Formula |
    50→|----|-------------|---------|
    51→| 1 | Perturbation | δL = (1/2) δW^T H δW |
    52→| 2 | Element-wise | δL = (1/2) Σ_l Σ_j∈cin Σ_i∈cout h^l_{i,j} · (w^l_{i,j} - Q(w^l_{i,j}))² |
    53→| 4 | Decomposition | Inter: min Σ_l h_l · δw_l;  Intra: min Σ_j Σ_i h^l_{i,j} · δw^l_{i,j}²  s.t. Q_{i,j} ∈ Q*_l |
    54→| 5 | Per-element sensitivity | S^l_{i,j} = (1/2) h^l_{i,j} · (w^l_{i,j} - Q(w^l_{i,j}))² |
    55→| 6 | Fisher approx | H ≈ F = (1/|D|) Σ_D g g^T |
    56→| 7 | Inter-layer sensitivity | S^l_InterMQ = (1/2) · (1/|D|) Σ_D Σ_i∈cout (g^T δw^l_{i,:})² |
    57→| 8 | Sensitivity-determined mapping | U_l = (S^l · r_l) / (Σ S^l · r_l) · (Ut - Ub) + Ub |
    58→| 9 | Param ratio | r_l = (c^l_in · c^l_out) / min_l(c^l_in · c^l_out) |
    59→| 10/24 | Intra-layer per-element | S^l_{i,j} = (1/2)(w - Q(w))² / [(X X^T + λ·mean(diag(X X^T))·I)^{-1}]_{j,j} |
    60→| 11 | Manhattan channel sens | S_IntraMQ_j = Σ_i∈cout |S^l_{i,j}| |
    61→| 12 | TopK identification | Csen = I(S_IntraMQ, K), K = ⌊c_in · U_l⌉ |
    62→
    63→**Key Design Decisions (from Appendix A):**
    64→
    65→1. **Fisher for inter-layer (NOT XX^T)**: H=XX^T has bias toward deeper layers (hidden states grow with depth). Fisher is "agnostic to hidden states magnitude" → better for inter-layer.
    66→
    67→2. **XX^T for intra-layer (NOT Fisher)**: Fisher requires explicit inverse → infeasible for cin × cin matrix. XX^T + Cholesky is efficient. Fisher for intra-layer adds 8.9GB + 6min on Llama-2-7B.
    68→
    69→3. **Parallel Layer Constraint**:
    70→   - **Inter-layer (bit allocation)**: average sensitivities of q/k/v (same bits); average of up/gate (same bits)
    71→   - **Intra-layer (permutation)**: CONCATENATE per-element sensitivity matrices of parallel layers, THEN apply Manhattan norm → same permutation indices
    72→
    73→4. **Permutation Fusion**:
    74→   - q/k/v input permutation → fused INTO prior RMSNorm
    75→   - up/gate input permutation → fused INTO prior activation function
    76→   - Zero runtime overhead
    77→
    78→5. **Decoupled Permutation**:
    79→   - Step 1: Sort channels ASCENDING by sensitivity → partition into Csen (top K) and Cinsen (rest)
    80→   - Step 2: Within Csen, sort by magnitude → minimize variance
    81→   - Step 3: Within Cinsen, sort by magnitude → minimize variance
    82→   - Final order = concat(Csen_sorted, Cinsen_sorted)
    83→   - Permutation metric: product of activations × weights l∞ norm
    84→
    85→**Hyperparameters:**
    86→- Format: W4.8A8 = W4A8 + 20% W8A8 (so Ut = 0.20)
    87→- UB (base high-precision ratio) = 12.5% (so Ub = 0.125)
    88→- λ (dampening factor) = 0.1
    89→- Group size = 128
    90→- Calibration: 128 samples from WikiText2, 2048 tokens each
    91→- Per-group symmetric static quantization for both W and A
    92→
    93→**Ablation Results (Llama-2-7B):**
    94→- Fisher inter + XX^T intra: WikiText 5.58, Avg 70.19 (BEST)
    95→- XX^T both: WikiText 5.61, Avg 69.69
    96→- Fisher both: WikiText 5.58, Avg 69.93 (same quality but +8.9GB +6min)
    97→
    98→**Performance:**
    99→- Qwen2.5-7B-Instruct: 75.58% zero-shot avg (vs FP16 75.71%, gap 0.13%)
   100→- Speedup: 1.83× to 4.21× (layer-wise), avg 2.86×
   101→- Sensitivity computation time: 59s (1.5B), 416s (7B), 668s (14B)
   102→
   103→**Pipeline (per SHMQ paper):**
   104→1. Compute inter-layer Fisher sensitivity (Eq. 7)
   105→2. Convert to per-layer high-precision ratio U_l (Eq. 8) — or use ILP (our improvement)
   106→3. Compute intra-layer per-element sensitivity via OBS (Eq. 10)
   107→4. Aggregate to per-channel via Manhattan norm (Eq. 11)
   108→5. TopK identification (Eq. 12)
   109→6. Decoupled permutation (sort by sensitivity → partition → sort by magnitude)
   110→7. Permutation fusion into RMSNorm/activation
   111→8. Quantize: sensitive channels → INT8, insensitive → INT4
   112→
   113→**Our SHMQ-Ultimate Improvements over original SHMQ:**
   114→- ILP (HAWQ-V3) instead of proportion mapping (Eq. 8) — mathematically optimal
   115→- AutoRound SignSGD for learnable rounding direction (vs RTN in original SHMQ)
   116→- SmoothQuant pre-processing for activation outlier migration
   117→- SQC calibration from SliM-LLM for scale/zero-point optimization
   118→- Fisher + PyHessian switch (test both, default Fisher per paper)

   139→## Smooth Function (CORE)
   140→- File: `/home/z/my-project/shmq-ultimate/external/SmoothQuant/smoothquant/smooth.py`
   141→- Functions: `smooth_ln_fcs` (LayerNorm bias case), `smooth_ln_fcs_llama_like` (RMSNorm no-bias case), `smooth_lm` (dispatcher).
   142→- Algorithm:
   143→  1. For each (norm_layer, [fc...]) pair to be smoothed:
   144→  2. Compute `weight_scales = max(|W_fc|)` per input-channel, concatenated across all sibling fcs, then take the max across siblings (handles shared-input Linears like q/k/v).
   145→  3. Compute `scales = (act_scales^alpha) / (weight_scales^(1-alpha))`, clamp(min=1e-5).
   146→  4. Migrate scales into weights and norm: `ln.weight /= s; ln.bias /= s` (only when bias exists, i.e. LayerNorm); `fc.weight *= s` (broadcasting over output rows, scaling input columns).
   147→- Mathematical formula:
   148→  - `s_j = (max|X_j|)^alpha / (max|W_j|)^(1-alpha)`
   149→  - `W'_j = W_j * s_j`  (smooth weights — they absorb the outlier magnitude)
   150→  - `x'_j = x_j / s_j`  (smooth activations — done implicitly via the norm's `1/s` factor; RMSNorm/LayerNorm divides by the scaling factor that was baked into its weight/bias).
   151→  - **Equivalent identity**: `Linear(Norm(x), W) ≡ Linear(Norm(x / s), W * s)` because Norm has elementwise `weight` and `bias` (LayerNorm) or `weight` only (RMSNorm). The math: dividing `ln.weight` by `s` is the same as dividing the post-Norm activation by `s`.
   152→- Bias handling: For LayerNorm models (OPT, BLOOM, Falcon), `ln.bias.div_(scales)` is required because LN bias is added AFTER the elementwise weight scale. For RMSNorm models (Llama, Mistral, Mixtral, Qwen2), there is NO bias — only `ln.weight.div_(scales)`.
   153→- Alpha usage: `alpha=0.5` is the function default (balances weight and activation difficulty equally). In practice, LLMs need higher alpha (0.8-0.9) because activations have very large systematic outliers compared to weights. Higher alpha → larger `s` → more outlier magnitude migrated to weights (since `s = act^alpha / weight^(1-alpha)` grows with `act`).

   156→```python
   157→import torch
   158→import torch.nn as nn
   159→
   160→from transformers.models.opt.modeling_opt import OPTDecoderLayer
   161→from transformers.models.bloom.modeling_bloom import BloomBlock
   162→from transformers.models.llama.modeling_llama import LlamaDecoderLayer, LlamaRMSNorm
   163→from transformers.models.mistral.modeling_mistral import (
   164→    MistralDecoderLayer,
   165→    MistralRMSNorm,
   166→)
   167→from transformers.models.mixtral.modeling_mixtral import (
   168→    MixtralDecoderLayer,
   169→    MixtralRMSNorm,
   170→)
   171→from transformers.models.falcon.modeling_falcon import FalconDecoderLayer
   172→
   173→# NOTE for SHMQ-Ultimate / Qwen2.5 integration:
   174→#   add:  from transformers.models.qwen2.modeling_qwen2 import Qwen2DecoderLayer, Qwen2RMSNorm
   175→#   and extend isinstance checks:
   176→#     - smooth_ln_fcs_llama_like: isinstance(ln, (LlamaRMSNorm, MistralRMSNorm, MixtralRMSNorm, Qwen2RMSNorm))
   177→#     - smooth_lm: isinstance(module, (LlamaDecoderLayer, MistralDecoderLayer, Qwen2DecoderLayer))
   178→
   179→
   180→@torch.no_grad()
   181→def smooth_ln_fcs(ln, fcs, act_scales, alpha=0.5):
   182→    """For LayerNorm models (OPT, BLOOM, Falcon). ln has bias."""
   183→    if not isinstance(fcs, list):
   184→        fcs = [fcs]
   185→    assert isinstance(ln, nn.LayerNorm)
   186→    for fc in fcs:
   187→        assert isinstance(fc, nn.Linear)
   188→        assert ln.weight.numel() == fc.in_features == act_scales.numel()
   189→
   190→    device, dtype = fcs[0].weight.device, fcs[0].weight.dtype
   191→    act_scales = act_scales.to(device=device, dtype=dtype)
   192→    # Per-input-channel max(|W|), max across sibling fcs (e.g. q/k/v share input)
   193→    weight_scales = torch.cat(
   194→        [fc.weight.abs().max(dim=0, keepdim=True)[0] for fc in fcs], dim=0
   195→    )
   196→    weight_scales = weight_scales.max(dim=0)[0].clamp(min=1e-5)
   197→
   198→    scales = (
   199→        (act_scales.pow(alpha) / weight_scales.pow(1 - alpha))
   200→        .clamp(min=1e-5)
   201→        .to(device)
   202→        .to(dtype)
   203→    )
   204→
   205→    ln.weight.div_(scales)
   206→    ln.bias.div_(scales)            # <-- LayerNorm has bias; RMSNorm does NOT
   207→
   208→    for fc in fcs:
   209→        fc.weight.mul_(scales.view(1, -1))   # broadcast over output dim, scale input columns
   210→
   211→
   212→@torch.no_grad()
   213→def smooth_ln_fcs_llama_like(ln, fcs, act_scales, alpha=0.5):
   214→    """For RMSNorm models (Llama, Mistral, Mixtral, Qwen2). ln has NO bias."""
   215→    if not isinstance(fcs, list):
   216→        fcs = [fcs]
   217→    assert isinstance(ln, (LlamaRMSNorm, MistralRMSNorm, MixtralRMSNorm))
   218→    for fc in fcs:
   219→        assert isinstance(fc, nn.Linear)
   220→        assert ln.weight.numel() == fc.in_features == act_scales.numel()
   221→    device, dtype = fcs[0].weight.device, fcs[0].weight.dtype
   222→    act_scales = act_scales.to(device=device, dtype=dtype)
   223→    weight_scales = torch.cat(
   224→        [fc.weight.abs().max(dim=0, keepdim=True)[0] for fc in fcs], dim=0
   225→    )
   226→    weight_scales = weight_scales.max(dim=0)[0].clamp(min=1e-5)
   227→    scales = (
   228→        (act_scales.pow(alpha) / weight_scales.pow(1 - alpha))
   229→        .clamp(min=1e-5)
   230→        .to(device)
   231→        .to(dtype)
   232→    )
   233→
   234→    ln.weight.div_(scales)
   235→    # NO bias for RMSNorm
   236→    for fc in fcs:
   237→        fc.weight.mul_(scales.view(1, -1))
   238→
   239→
   240→@torch.no_grad()
   241→def smooth_lm(model, scales, alpha=0.5):
   242→    """Top-level dispatcher: iterate over modules and smooth each (Norm, FCs) pair.
   243→       `scales` is a dict: layer_name -> 1D tensor of per-channel max(|X|).
   244→    """
   245→    for name, module in model.named_modules():
   246→        if isinstance(module, OPTDecoderLayer):
   247→            attn_ln = module.self_attn_layer_norm
   248→            qkv = [module.self_attn.q_proj, module.self_attn.k_proj, module.self_attn.v_proj]
   249→            qkv_input_scales = scales[name + ".self_attn.q_proj"]
   250→            smooth_ln_fcs(attn_ln, qkv, qkv_input_scales, alpha)
   251→
   252→            ffn_ln = module.final_layer_norm
   253→            fc1 = module.fc1
   254→            fc1_input_scales = scales[name + ".fc1"]
   255→            smooth_ln_fcs(ffn_ln, fc1, fc1_input_scales, alpha)
   256→        # ... (BloomBlock, FalconDecoderLayer branches omitted — see source)
   257→        elif isinstance(module, (LlamaDecoderLayer, MistralDecoderLayer)):
   258→            attn_ln = module.input_layernorm
   259→            qkv = [module.self_attn.q_proj, module.self_attn.k_proj, module.self_attn.v_proj]
   260→            qkv_input_scales = scales[name + ".self_attn.q_proj"]
   261→            smooth_ln_fcs_llama_like(attn_ln, qkv, qkv_input_scales, alpha)
   262→
   263→            ffn_ln = module.post_attention_layernorm
   264→            fcs = [module.mlp.gate_proj, module.mlp.up_proj]

   288→## Activation Scale Calibration
   289→- File: `/home/z/my-project/shmq-ultimate/external/SmoothQuant/smoothquant/calibration.py`
   290→- Function: `get_act_scales(model, tokenizer, dataset_path, num_samples=512, seq_len=512)`
   291→- Hook mechanism: Registers forward hooks on every `nn.Linear` module via `model.named_modules()`. Each hook captures the INPUT tensor `x` (first tuple element if x is tuple). Hooks are removed after calibration.
   292→- Aggregation: For each Linear input `x` of shape (..., hidden_dim), reshape to `(-1, hidden_dim)`, take `abs()`, then `max(dim=0)` → per-channel `max(|X|)`. Across samples, the running max is kept via `torch.max(act_scales[name], coming_max)`.
   293→- Storage format: Python dict mapping `{module_name (str): tensor (1D, length=hidden_dim, dtype=float32, on CPU)}`. Saved via `torch.save(act_scales, path)` → loadable as `torch.load(path)`.
   294→- Defaults: 512 samples, seq_len=512, Pile validation set (`mit-han-lab/pile-val-backup` → `val.jsonl.zst`).
   295→
   296→### KEY CODE: calibration.py
   297→```python
   298→import torch
   299→import torch.nn as nn
   300→import functools
   301→from datasets import load_dataset
   302→from tqdm import tqdm
   303→
   304→
   305→def get_act_scales(model, tokenizer, dataset_path, num_samples=512, seq_len=512):
   306→    model.eval()
   307→    device = next(model.parameters()).device
   308→    act_scales = {}
   309→
   310→    def stat_tensor(name, tensor):
   311→        hidden_dim = tensor.shape[-1]
   312→        tensor = tensor.view(-1, hidden_dim).abs().detach()
   313→        coming_max = torch.max(tensor, dim=0)[0].float().cpu()
   314→        if name in act_scales:
   315→            act_scales[name] = torch.max(act_scales[name], coming_max)
   316→        else:
   317→            act_scales[name] = coming_max
   318→
   319→    def stat_input_hook(m, x, y, name):
   320→        if isinstance(x, tuple):
   321→            x = x[0]
   322→        stat_tensor(name, x)
   323→
   324→    hooks = []
   325→    for name, m in model.named_modules():
   326→        if isinstance(m, nn.Linear):
   327→            hooks.append(
   328→                m.register_forward_hook(functools.partial(stat_input_hook, name=name))
   329→            )
   330→
   331→    dataset = load_dataset("json", data_files=dataset_path, split="train")
   332→    dataset = dataset.shuffle(seed=42)
   333→
   334→    for i in tqdm(range(num_samples)):
   335→        input_ids = tokenizer(
   336→            dataset[i]["text"], return_tensors="pt", max_length=seq_len, truncation=True
   337→        ).input_ids.to(device)
   338→        model(input_ids)
   339→
   340→    for h in hooks:
   341→        h.remove()
   342→
   343→    return act_scales
   344→```
   345→Note for SHMQ-Ultimate: SHMQ paper uses 128 samples × 2048 tokens (WikiText2), vs SmoothQuant's 512 × 512 (Pile). We can keep the SmoothQuant defaults since the calibration is only for the smoothing step (not for sensitivity computation, which has its own calibration).

   362→### KEY CODE: fake_quant.py (core quantizers + W8A8Linear)
   363→```python
   364→import torch
   365→from torch import nn
   366→from functools import partial
   367→
   368→
   369→@torch.no_grad()
   370→def quantize_weight_per_channel_absmax(w, n_bits=8):
   371→    # w: (out_features, in_features); scale per output row
   372→    scales = w.abs().max(dim=-1, keepdim=True)[0]
   373→    q_max = 2 ** (n_bits - 1) - 1
   374→    scales.clamp_(min=1e-5).div_(q_max)
   375→    w.div_(scales).round_().mul_(scales)
   376→    return w
   377→
   378→
   379→@torch.no_grad()
   380→def quantize_weight_per_tensor_absmax(w, n_bits=8):
   381→    scales = w.abs().max()
   382→    q_max = 2 ** (n_bits - 1) - 1
   383→    scales.clamp_(min=1e-5).div_(q_max)
   384→    w.div_(scales).round_().mul_(scales)
   385→    return w
   386→
   387→
   388→@torch.no_grad()
   389→def quantize_activation_per_token_absmax(t, n_bits=8):
   390→    # t: (..., hidden); scale per token (per row after view)
   391→    t_shape = t.shape
   392→    t.view(-1, t_shape[-1])
   393→    scales = t.abs().max(dim=-1, keepdim=True)[0]
   394→    q_max = 2 ** (n_bits - 1) - 1
   395→    scales.clamp_(min=1e-5).div_(q_max)
   396→    t.div_(scales).round_().mul_(scales)
   397→    return t
   398→
   399→
   400→@torch.no_grad()
   401→def quantize_activation_per_tensor_absmax(t, n_bits=8):
   402→    t_shape = t.shape
   403→    t.view(-1, t_shape[-1])
   404→    scales = t.abs().max()
   405→    q_max = 2 ** (n_bits - 1) - 1
   406→    scales.clamp_(min=1e-5).div_(q_max)
   407→    t.div_(scales).round_().mul_(scales)
   408→    return t
   409→
   410→
   411→# === SHMQ-Ultimate extension: per-group weight quantization (group_size=128) ===
   412→@torch.no_grad()
   413→def quantize_weight_per_group_absmax(w, group_size=128, n_bits=4):
   414→    # w: (out_features, in_features); assume in_features % group_size == 0
   415→    out_features, in_features = w.shape
   416→    assert in_features % group_size == 0
   417→    w_grouped = w.view(out_features, in_features // group_size, group_size)
   418→    scales = w_grouped.abs().amax(dim=-1, keepdim=True)
   419→    q_max = 2 ** (n_bits - 1) - 1
   420→    scales.clamp_(min=1e-5).div_(q_max)
   421→    w_grouped.div_(scales).round_().mul_(scales)
   422→    return w.view(out_features, in_features)
   423→
   424→
   425→class W8A8Linear(nn.Module):
   426→    def __init__(self, in_features, out_features, bias=True,
   427→                 act_quant="per_token", quantize_output=False):
   428→        super().__init__()
   429→        self.in_features = in_features
   430→        self.out_features = out_features
   431→        self.register_buffer("weight", torch.randn(out_features, in_features,
   432→                                                   dtype=torch.float16, requires_grad=False))
   433→        if bias:
   434→            self.register_buffer("bias", torch.zeros((1, out_features),
   435→                                                    dtype=torch.float16, requires_grad=False))
   436→        else:
   437→            self.register_buffer("bias", None)
   438→        if act_quant == "per_token":
   439→            self.act_quant = partial(quantize_activation_per_token_absmax, n_bits=8)
   440→        else:
   441→            self.act_quant = partial(quantize_activation_per_tensor_absmax, n_bits=8)
   442→        self.output_quant = self.act_quant if quantize_output else (lambda x: x)
   443→
   444→    @torch.no_grad()
   445→    def forward(self, x):
   446→        q_x = self.act_quant(x)
   447→        y = torch.functional.F.linear(q_x, self.weight, self.bias)
   448→        return self.output_quant(y)
   449→
   450→    @staticmethod
   451→    def from_float(module, weight_quant="per_channel", act_quant="per_token", quantize_output=False):
   452→        assert isinstance(module, torch.nn.Linear)
   453→        new_module = W8A8Linear(module.in_features, module.out_features,
   454→                                module.bias is not None, act_quant, quantize_output)
   455→        if weight_quant == "per_channel":
   456→            new_module.weight = quantize_weight_per_channel_absmax(module.weight, n_bits=8)
   457→        else:
   458→            new_module.weight = quantize_weight_per_tensor_absmax(module.weight, n_bits=8)
   459→        if module.bias is not None:
   460→            new_module.bias = module.bias
   461→        return new_module
   462→
   463→
   464→def quantize_llama_like(model, weight_quant="per_channel", act_quant="per_token",
   465→                        quantize_bmm_input=False):
   466→    """SHMQ-Ultimate: use this pattern for Qwen2 (same module structure)."""
   467→    from transformers.models.llama.modeling_llama import LlamaAttention, LlamaMLP
   468→    for name, m in model.model.named_modules():
   469→        if isinstance(m, LlamaMLP):
   470→            m.gate_proj = W8A8Linear.from_float(m.gate_proj, weight_quant, act_quant)
   471→            m.up_proj   = W8A8Linear.from_float(m.up_proj,   weight_quant, act_quant)
   472→            m.down_proj = W8A8Linear.from_float(m.down_proj, weight_quant, act_quant)
   473→        elif isinstance(m, LlamaAttention):
   474→            m.q_proj = W8A8Linear.from_float(m.q_proj, weight_quant, act_quant, quantize_bmm_input)
   475→            m.k_proj = W8A8Linear.from_float(m.k_proj, weight_quant, act_quant, quantize_bmm_input)
   476→            m.v_proj = W8A8Linear.from_float(m.v_proj, weight_quant, act_quant, quantize_bmm_input)
   477→            m.o_proj = W8A8Linear.from_float(m.o_proj, weight_quant, act_quant)
   478→    return model
   479→```

   545→## Integration Notes for SHMQ-Ultimate
   546→- SmoothQuant is **Step 1** of the SHMQ-Ultimate pipeline (pre-processing for activation outlier migration).
   547→- After smooth:
   548→  - Weights have higher dynamic range (absorbed outlier magnitude).
   549→  - Activations are smoother (per-channel outliers reduced).
   550→- Then the SHMQ pipeline runs on the **smoothed weights**:
   551→  - Step 2: SHMQ sensitivity computation (Fisher inter-layer + XX^T intra-layer, Eq.7/10).
   552→  - Step 3: ILP bit allocation (HAWQ-V3 PULP solver, replaces Eq.8 proportion mapping).
   553→  - Step 4: Decoupled permutation (sort by sensitivity → partition → sort by magnitude).
   554→  - Step 5: Permutation fusion into RMSNorm/activation (zero runtime overhead).
   555→  - Step 6: AutoRound SignSGD for learnable rounding (200 steps, replaces RTN).
   556→  - Step 7: SQC calibration for scale/zero-point optimization.
   557→  - Step 8: Quantize: sensitive channels → INT8, insensitive → INT4 (mixed W4/W8, all A8).
   558→- **Critical interaction**: SmoothQuant's smoothing MUST be applied BEFORE SHMQ sensitivity computation, because:
   559→  - The sensitivity (Eq.10) is `(w - Q(w))² × H^{-1}` — this depends on the ACTUAL weight values after smoothing.
   560→  - The Hessian H ≈ XX^T also depends on the smoothed activations (per-token outliers reduced).
   561→  - If we smooth AFTER sensitivity computation, the bit allocation would be wrong.
   562→- **Critical interaction with permutation**: SHMQ permutes channels (Csen vs Cinsen). Smoothing factors `s_j` are per-channel — they must be applied BEFORE permutation so that the permuted weights carry the migrated magnitudes correctly. The smoothing scales `s` themselves do NOT need to be permuted (they are absorbed into the weights and RMSNorm weight at smoothing time, before any permutation).
   563→- **Reusability**: We can vendor the 3 functions (`smooth_ln_fcs`, `smooth_ln_fcs_llama_like`, `smooth_lm`) + `get_act_scales` + the 4 fake_quant functions essentially as-is (with Qwen2RMSNorm/Qwen2DecoderLayer additions). Total ~250 LOC. The `opt.py` real-INT8 path (with torch-int/CUTLASS) is NOT needed.

   598→## Per-element Hessian (OBS) — for SHMQ Eq. 10
   599→
   600→- File: `/home/z/my-project/shmq-ultimate/external/SliM-LLM/slim-llm/slim_gptq.py`
   601→- Functions: `SliMGPTQ.add_batch()`, `SliMGPTQ.get_salience()`, `SliMGPTQ.fasterquant()`
   602→- Algorithm:
   603→  1. Accumulate `H = Σ X X^T / nsamples` across calibration batches (rescaled by `sqrt(2/nsamples)`).
   604→  2. Compute H^{-1} via Cholesky: `H → cholesky → cholesky_inverse → cholesky(upper=True) = Hinv`.
   605→  3. Per-element OBS quantization error contribution = `(w - Q(w))² / (Hinv_{j,j})²` ≈ `w² / (Hinv_{j,j})²` (proxy used pre-quantization for block-level salience).
   606→  4. **Dampening**: `H[diag,diag] += percdamp * mean(diag(H))` (default `percdamp=0.01`) — matches SHMQ Eq. 10's `λ·mean(diag(X X^T))`.
   607→  5. Dead-column handling: `H[dead,dead]=1`, `W[:,dead]=0`.
   608→- Key code (Hessian accumulation):
   609→```python
   610→# slim_gptq.py: SliMGPTQ.add_batch
   611→def add_batch(self, inp, out, blocksize=1024):
   612→    if len(inp.shape) == 2:
   613→        inp = inp.unsqueeze(0)
   614→    tmp = inp.shape[0]
   615→    if isinstance(self.layer, nn.Linear) or isinstance(self.layer, transformers.Conv1D):
   616→        if len(inp.shape) == 3:
   617→            inp = inp.reshape((-1, inp.shape[-1]))
   618→        inp = inp.t()
   619→    self.H *= self.nsamples / (self.nsamples + tmp)
   620→    self.nsamples += tmp
   621→    inp = math.sqrt(2 / self.nsamples) * inp.float()
   622→    self.H += inp.matmul(inp.t())   # H = (2/n) * X X^T
   623→```
   624→- Key code (H^{-1} + per-element salience, matches SHMQ Eq. 10):
   625→```python
   626→# slim_gptq.py: get_salience()
   627→def get_salience(self, blocksize=128):
   628→    h = self.H
   629→    w = self.layer.weight.data.clone()
   630→    dead = torch.diag(h) == 0
   631→    h[dead, dead] = 1
   632→    diag = torch.arange(self.columns, device=self.dev)
   633→    damp = 0.01                                  # ← SHMQ uses 0.1*mean(diag); fasterquant uses 0.01*mean(diag)
   634→    h[diag, diag] += damp
   635→    h = torch.linalg.cholesky(h)
   636→    h = torch.cholesky_inverse(h)
   637→    h = torch.linalg.cholesky(h, upper=True)
   638→    Hinv = h
   639→    for blocki, col_st in enumerate(range(0, self.columns, blocksize)):
   640→        col_ed = min(col_st + blocksize, self.columns)
   641→        # Per-element salience S_{i,j} = w_{i,j}^2 / (Hinv_{j,j})^2  (matches Eq. 10 with (w-Q(w))≈w proxy)
   642→        block_value = w[:, st:ed] ** 2 / (torch.diag(Hinv[st:ed, st:ed]).reshape((1, -1))) ** 2
   643→        self.block_salience.append(torch.sum(block_value).item())
   644→```

   646→## GPTQ Algorithm Core
   647→
   648→- File: `/home/z/my-project/shmq-ultimate/external/SliM-LLM/AutoGPTQ/auto_gptq/quantization/gptq.py` (vanilla; identical core in `slim_gptq.py`)
   649→- Function: `GPTQ.fasterquant()` (blocksize=128, percdamp=0.01, group_size=128)
   650→- Algorithm (Frantar 2023 OBS-style weight update):
   651→  1. For each 128-column block, slice `W1 = W[:, i1:i2]`, `Hinv1 = Hinv[i1:i2, i1:i2]`.
   652→  2. For each column i inside the block: quantize `w = W1[:, i]` → `q`; compute quantization error `err1 = (w - q) / Hinv1[i,i]`; **propagate error to remaining columns in the block**: `W1[:, i:] -= err1 @ Hinv1[i, i:]`.
   653→  3. After the block: **propagate accumulated block error to all subsequent blocks**: `W[:, i2:] -= Err1 @ Hinv[i1:i2, i2:]`.
   654→  4. Loss per element = `(w - q)² / d²` (OBS quantization loss).
   655→- Key code:
   656→```python
   657→# gptq.py: GPTQ.fasterquant — the OBS weight update
   658→damp = percdamp * torch.mean(torch.diag(H))
   659→diag = torch.arange(self.columns, device=self.dev)
   660→H[diag, diag] += damp
   661→H = torch.linalg.cholesky(H)
   662→H = torch.cholesky_inverse(H)
   663→H = torch.linalg.cholesky(H, upper=True)
   664→Hinv = H
   665→
   666→for i1 in range(0, self.columns, blocksize):
   667→    i2 = min(i1 + blocksize, self.columns)
   668→    count = i2 - i1
   669→    W1 = W[:, i1:i2].clone()
   670→    Q1 = torch.zeros_like(W1)
   671→    Err1 = torch.zeros_like(W1)
   672→    Losses1 = torch.zeros_like(W1)
   673→    Hinv1 = Hinv[i1:i2, i1:i2]
   674→    for i in range(count):
   675→        w = W1[:, i]
   676→        d = Hinv1[i, i]
   677→        if group_size != -1 and (i1 + i) % group_size == 0:
   678→            self.quantizer.find_params(W[:, (i1+i):(i1+i+group_size)], weight=True)
   679→        q = self.quantizer.quantize(w.unsqueeze(1)).flatten()
   680→        Q1[:, i] = q
   681→        Losses1[:, i] = (w - q) ** 2 / d**2
   682→        err1 = (w - q) / d
   683→        # propagate error to remaining columns in the block (OBS)
   684→        W1[:, i:] -= err1.unsqueeze(1).matmul(Hinv1[i, i:].unsqueeze(0))
   685→        Err1[:, i] = err1
   686→    Q[:, i1:i2] = Q1
   687→    Losses[:, i1:i2] = Losses1 / 2
   688→    # propagate block error to all subsequent blocks
   689→    W[:, i2:] -= Err1.matmul(Hinv[i1:i2, i2:])
   690→```
   691→- Difference vs SliM-LLM `SliMGPTQ.fasterquant`: SliM-LLM adds a per-block `block_bit` chosen from {bit_width-1, bit_width, bit_width+1} based on SBA labels, and uses the salience-aware `Quantizer.fit(W1, Hinv1, bit_width=block_bit)` (SQC) instead of vanilla `find_params()`.

   696→- Functions: `Quantizer.fit(w, Hinv1, bit_width)`, `Quantizer.quantize(w, bit_width)`
   697→- Algorithm:
   698→  1. Compute per-element salience: `float_sensitivity = w² / (diag(Hinv1))²` (same as Eq. 10).
   699→  2. Use `saliency_mask()` (z-score > 2 from `salient_mask.py`) to split weights into `mask0` (nonsalient) and `mask1` (salient).
   700→  3. Initialize scale/zero from per-channel min/max (asymmetric: `scale = (xmax-xmin)/maxq`, `zero = round(-xmin/scale)`).
   701→  4. **Grid search** scale multiplier `p ∈ [1.0, 1.1] ∪ [1.0, 0.9]` (50 points each side; `tau_range=0.1`, `tau_n=50`):
   702→     - `xmin1 = p*xmin`, `xmax1 = p*xmax`, `scale1 = (xmax1-xmin1)/maxq`.
   703→     - Quantize, then split quantization error into salient (`err_s`) and nonsalient (`err_ns`) components.
   704→     - Total error: `err = err_ns + lambda_salience * err_s` (salient errors penalized more heavily).
   705→     - Pick `p` (and corresponding `scale`, `zero`) minimizing per-channel combined error.
   706→  5. Default `lambda_salience=1.0`; `norm=2.4` (L2.4 norm); `metric='mse'`.
   707→- Key code:
   708→```python
   709→# mixed_quantizer.py: Quantizer.fit — SQC
   710→def fit(self, w, Hinv1, bit_width=0):
   711→    bits = int(self.method[0])
   712→    maxq = torch.tensor(2 ** bits - 1)
   713→    # per-element salience (Eq. 10)
   714→    float_sensitivity = (w ** 2 / (torch.diag(Hinv1).reshape((1, -1))) ** 2)
   715→    mask0, mask1 = saliency_mask(float_sensitivity)   # mask1=salient, mask0=nonsalient
   716→    # ... initial scale/zero from min/max ...
   717→    tau_range, tau_n = 0.1, 50
   718→    best = torch.full([x.shape[0]], float('inf'), device=dev)
   719→    p_grid = torch.cat([torch.ones(1),
   720→                        torch.linspace(1.0, 1+tau_range, tau_n+1)[1:],
   721→                        torch.linspace(1.0, 1-tau_range, tau_n+1)[1:]])
   722→    for p in p_grid:
   723→        xmin1, xmax1 = p * xmin, p * xmax
   724→        scale1 = (xmax1 - xmin1) / maxq
   725→        zero1  = torch.round(-xmin1/scale1) if not self.sym else zero
   726→        w_ns = torch.where(mask0, x, torch.tensor(float('nan')))
   727→        w_s  = torch.where(mask1, x, torch.tensor(float('nan')))
   728→        w_q  = normal_quantize(x, scale1.unsqueeze(1), zero1.unsqueeze(1), maxq)
   729→        w_q_ns = torch.where(mask0, w_q, torch.tensor(float('nan')))
   730→        w_q_s  = torch.where(mask1, w_q, torch.tensor(float('nan')))
   731→        err_ns = torch.nansum((w_q_ns - w_ns).abs_().pow_(self.norm), 1)
   732→        err_s  = torch.nansum((w_q_s  - w_s ).abs_().pow_(self.norm), 1)
   733→        err = err_ns + self.lambda_salience * err_s       # salience-weighted error
   734→        tmp = err < best
   735→        if torch.any(tmp):
   736→            _p[tmp]=p; best[tmp]=err[tmp]; scale[tmp]=scale1[tmp]; zero[tmp]=zero1[tmp]
   737→```
   738→- Supporting file: `/external/SliM-LLM/slim-llm/utils/salient_mask.py`
   739→```python
   740→def saliency_mask(hessian_matrix):
   741→    threshold = 2
   742→    mean = torch.mean(hessian_matrix)
   743→    std_dev = torch.std(hessian_matrix)
   744→    z_scores = (hessian_matrix - mean) / std_dev
   745→    outliers = hessian_matrix[torch.abs(z_scores) > threshold]
   746→    ourlier_min_values = torch.min(outliers)
   747→    return generate_mask(hessian_matrix, ourlier_min_values)

   750→## SBA (Salience-Based Allocation)
   751→
   752→- File: `/home/z/my-project/shmq-ultimate/external/SliM-LLM/slim-llm/utils/bitsearch.py`
   753→- Function: `activation_aware_search(salience_array, new_labels, w, columns, blocksize, bit_width, activation_in, activation_out)`
   754→- Algorithm:
   755→  1. Sort blocks by salience (ascending). For each candidate count `i ∈ [1, n_blocks/2]`:
   756→     - Top-i salient blocks → label 2 → high bit (`bit_width+1`)
   757→     - Bottom-i salient blocks → label 0 → low bit (`bit_width-1`)
   758→     - Rest → label 1 → base bit (`bit_width`)
   759→  2. Apply block-level RTN quantization (`block_quantize`).
   760→  3. Compute KL-divergence: `kl_div(activation_in @ W_quant.T, activation_out)` — measures output reconstruction error.
   761→  4. Returns `errors[]` array (indexed by `i`). The `i` minimizing error is selected as the count of high-bit/low-bit blocks.
   762→- Key code:
   763→```python
   764→def activation_aware_search(salience_array, new_labels, w, columns, blocksize, bit_width, activation_in, activation_out):
   765→    max_round = salience_array.shape[0] // 2
   766→    errors = []
   767→    for i in range(1, max_round):
   768→        tmp = torch.zeros_like(w)
   769→        min_indices = salience_array.argsort()[:i]    # bottom-i salient
   770→        max_indices = salience_array.argsort()[-i:]   # top-i salient
   771→        tmp_bits = new_labels.copy()
   772→        for j in min_indices: tmp_bits[j] = 0          # → bit_width-1
   773→        for j in max_indices: tmp_bits[j] = 2          # → bit_width+1
   774→        for blocki, col_st in enumerate(range(0, columns, blocksize)):
   775→            col_ed = min(col_st + blocksize, columns)
   776→            block_bit = (bit_width-1) if tmp_bits[blocki]==0 else \
   777→                        (bit_width+1) if tmp_bits[blocki]==2 else bit_width
   778→            tmp[:, col_st:col_ed] = block_quantize(w[:, col_st:col_ed], bit_width=block_bit)
   779→        error = kl_div(activation_in @ tmp.T, activation_out)
   780→        errors.append(error.item())
   781→    return errors
   782→```
   783→- Note for SHMQ: SBA is **block-level** (128 columns per block) and uses KL-div on activations. SHMQ uses **per-channel** (Manhattan norm, Eq. 11) and **TopK by U_l ratio** (Eq. 12). Both use the same per-element salience w²/diag(Hinv)² from Eq. 10, but differ in aggregation. We should adapt SBA's grid-search-over-K pattern, replacing KL-div with SHMQ's Fisher-based inter-layer sensitivity.

   884→from auto_gptq.quantization import GPTQ
   885→from auto_gptq.modelutils import find_layers   # or copy the recursive helper from slim-llm/modelutils.py
   886→

   888→subset = find_layers(layer)   # dict: {"self_attn.q_proj": Linear, "self_attn.k_proj": Linear, ...}
   889→
   890→# 2. Create a GPTQ wrapper per Linear, configure the quantizer
   891→gptq = {}
   892→for name in subset:
   893→    gptq[name] = GPTQ(subset[name])

   897→def add_batch(name):

   899→        gptq[name].add_batch(inp[0].data, out.data)
   900→    return tmp
   901→handles = [subset[name].register_forward_hook(add_batch(name)) for name in gptq]
   902→
   903→# 4. Forward pass calibration data through the layer
   904→for batch in dataloader:
   905→    layer(batch[0].to(dev), attention_mask=attention_mask)
   906→for h in handles: h.remove()
   907→
   908→# 5. Quantize each Linear with GPTQ
   909→quantizers = {}
   910→for name in gptq:
   911→    scale, zero, g_idx = gptq[name].fasterquant(
   912→        percdamp=0.01, blocksize=128, group_size=128, actorder=False, static_groups=False)
   913→    quantizers[f"model.layers.{i}.{name}"] = (gptq[name].quantizer, scale, zero, g_idx)
   914→    gptq[name].free()
   915→```

  1168→**Notes on the objective encoding (very important):**
  1169→- `x_i ∈ {1, 2}` where 1→4-bit and 2→8-bit (NOT a one-hot encoding — direct integer variable).
  1170→- `sensitivity_diff_i = Hessian_trace_i * (||W - Q8(W)||² - ||W - Q4(W)||²)` — this is NEGATIVE because `||W - Q8||² << ||W - Q4||²`.
  1171→- The objective term `(x_i - 1) * sensitivity_diff_i` equals:
  1172→  - `0 * sens_diff = 0` if `x_i = 1` (4-bit chosen)
  1173→  - `1 * sens_diff = sens_diff < 0` if `x_i = 2` (8-bit chosen)
  1174→- Minimizing → solver prefers `x_i = 2` (8-bit) to drive objective down, but the budget constraint caps how many can be 8-bit. The Hessian-weighted difference makes the solver prioritize assigning 8-bit to the most sensitive layers.

  1198→**Constraints to KEEP:**
  1199→- Memory budget (analog of `model_size`): `sum(0.5 * x_i * params_i_bytes) <= budget`. For W4.8A8 with 20% W8: `budget = (0.8 * 0.5 + 0.2 * 1.0) * total_params_bytes = 0.6 * total_params_bytes` (in the notebook's MB-normalized units).
  1200→- Objective: `minimize sum((x_i - 1) * hessian_trace_i * (delta_w8_sq_i - delta_w4_sq_i))` — exactly HAWQ-V3's formulation. NEGATIVE coefficient → solver prefers 8-bit for high-sensitivity layers.
  1201→- `x_i ∈ {1, 2}` integer variable encoding (1→4-bit, 2→8-bit).
  1202→
  1203→**Constraints to REMOVE (CNN-specific, irrelevant for LLMs):**
  1204→- `BOPS` constraint — BOPS = FLOPS weighted by bit-width; meaningful for CNN forward pass but for LLMs the dominant cost is **KV-cache memory + decode attention**, not matmul BOPS. Removing simplifies the problem to a single-constraint knapsack.
  1205→- `Latency` constraint — HAWQ's per-layer latency is T4-GPU INT4/INT8 kernel timing for CNN conv layers. LLM latency is bottlenecked by memory bandwidth and is roughly monotonic in total weight bytes — already captured by memory budget. Removing avoids needing per-kernel measurements.
  1206→
  1207→**Constraints to ADD (LLM-specific, from SHMQ paper Section 3.4):**
  1208→- **Parallel layer equality**: q/k/v_proj in the same attention block MUST share bit-width; up/gate_proj in the same MLP block MUST share bit-width. (down_proj is independent.) This is the SHMQ paper's "parallel layer constraint" for Inter-layer sensitivity. Encoded as `equality_groups` → for each group, add `x_i == x_j` for all pairs in the group.
  1209→- **Fixed layers**: embedding (`embed_tokens`), LM head (`lm_head`), and all normalization layers (RMSNorm/LayerNorm) typically stay at FP16 or are excluded. Encoded via `fixed_bits` dict — set variable bounds `[2, 2]` (i.e. fix x=2) or remove from problem entirely.
  1210→- **(Optional) KV-cache budget** — if we want to bound activation memory, can add a separate constraint on attention-layer activation bytes. Not in original HAWQ; document but leave optional for v1.
  1211→- **(Optional) Decode-step latency upper bound** — for deployment scenarios with latency SLO. v1: skip.
  1212→

The original HAWQ notebook calls `GLPK_CMD(msg=1, options=["--tmlim", "10000", "--simplex"])`. We must use `PULP_CBC_CMD(msg=0, timeLimit=10000)` instead — identical LP/MIP semantics, different solver backend.

  1217→| Function | Signature | Behavior |
  1218→|----------|-----------|----------|
  1219→| `clamp(input, min, max, inplace=False)` | tensor → tensor | Wraps `torch.clamp`. |
  1220→| `transfer_conv_size(t)` | `[N]` → `[1, N, 1, 1]` | Reshape 1-D scale for conv weights. |

  1228→| `batch_frexp(inputs)` | scale tensor → `(mantissa, exponent)` | Decomposes scale into `(m, e)` such that `scale = m * 2^(-e)`. **Critical for dyadic quantization** — converts arbitrary float scales into fixed-point shifts so all arithmetic stays integer-only on hardware. Uses `np.frexp` then converts mantissa to int32 (×2^31, ROUND_HALF_UP). |
  1229→| `ste_round` (autograd Function) | `x → round(x)` (forward); pass-through (backward) | STE for `torch.round` — allows gradients to flow through rounding op during QAT. |
  1230→| `SymmetricQuantFunction` (autograd Function) | `forward(x, k, specified_scale) → int_x`; `backward(grad) → grad / scale` | Symmetric fake-quant: `clamp(round(x / scale), -2^(b-1)-1, 2^(b-1)-1)`. Scale must be pre-computed (passed in). |
  1231→| `AsymmetricQuantFunction` (autograd Function) | `forward(x, k, scale, zero_point) → int_x`; `backward(grad) → grad / scale` | Asymmetric fake-quant for unsigned activations: `clamp(round(x/scale + zp), 0, 2^b - 1)`. |
  1232→| `transfer_float_averaging_to_int_averaging` (autograd Function) | `x → trunc(x + eps)` (forward); pass-through (backward) | STE for integer average pooling — handles cases like `48/49` needing to round to 1. |
  1233→| `fixedpoint_fn` (autograd Function) | see below | **THE HEART OF HAWQ-V3's dyadic quantization** — performs the integer-only fixed-point arithmetic required to match hardware. |
  1234→
  1235→**`fixedpoint_fn` in detail (HAWQ-V3's key contribution):**
  1236→- Signature: `forward(z, bitwidth, quant_mode, z_scaling_factor, case, pre_act_scaling_factor=None, pre_weight_scaling_factor=None, identity=None, identity_scaling_factor=None, identity_weight_scaling_factor=None)`
  1237→- `case=0`: simple `z = W·x`. Computes `z_int = round(z / pre_act_sf / pre_weight_sf)`, then rescales to `z_scaling_factor` using `batch_frexp(new_scale)` — i.e. `(z_int * m) / 2^e` rounded. Output clamped to bitwidth range.
  1238→- `case=1`: residual `z = W·x + W'·identity`. Splits `z` into the identity contribution and the new contribution, rescales each separately via `batch_frexp`, sums as integers.
  1239→- All arithmetic is integer + power-of-2 shifts (via mantissa/exponent) → no float division at inference → deployable on integer-only hardware (TVM, etc.).
  1240→- **For SHMQ-Ultimate (LLMs)**: we don't need integer-only deployment (we use AutoGPTQ + Marlin kernels which handle scale fusion internally). So we can SKIP `fixedpoint_fn` and use the simpler `SymmetricQuantFunction` + `linear_dequantize` path. **Keep `batch_frexp` documented as reference** in case we ever need integer-only LLM deployment.

  1265→        # 5. weight_integer = SymmetricQuantFunction(weight, weight_bit, fc_scaling_factor)
  1266→        # 6. bias_scaling_factor = fc_scaling_factor * prev_act_scaling_factor  (per-channel)
  1267→        # 7. bias_integer = SymmetricQuantFunction(bias, bias_bit, bias_scaling_factor)
  1268→        # 8. x_int = x / prev_act_scaling_factor
  1269→        # 9. output = ste_round(F.linear(x_int, weight_integer, bias_integer)) * correct_output_scale
  1270→        #    where correct_output_scale = bias_scaling_factor[0].view(1, -1)
  1271→        # NOTE: this returns a TENSOR, not a (tensor, scale) tuple — different from QuantConv2d
  1272→```
  1273→
  1274→**For SHMQ-Ultimate LLMs**: we will NOT directly reuse `QuantLinear` because:
  1275→1. It expects `prev_act_scaling_factor` as a runtime arg (dyadic integer-only inference style) — incompatible with our AutoGPTQ+Marlin path.
  1276→2. It computes scaling factor on-the-fly during forward (QAT-style) — but we use **post-training** quantization with AutoGPTQ.
  1277→3. No support for group quantization (group_size=128 per SHMQ spec).
  1278→
  1279→**Instead, we use `QuantLinear` as a reference for**:
  1280→- The per-channel scale computation pattern (`symmetric_linear_quantization_params(weight_bit, w_min, w_max, per_channel=True)`).
  1281→- The integer-arithmetic decomposition `output = F.linear(x_int, w_int, b_int) * output_scale` — Marlin does this internally but it's the same idea.
  1282→- The `weight_integer` / `bias_integer` buffer pattern for storing pre-quantized weights.
  1283→
  1284→Our SHMQ `QuantLinear` will wrap AutoGPTQ's `QuantLinear` and add: (a) per-channel bit mask (some channels 4-bit, others 8-bit per SHMQ spec), (b) Marlin kernel dispatch, (c) permutation fusion hooks for RMSNorm/activation. Build details deferred to Task 1.x.

  1336→
  1337→**Status**: BitPack is **external** — the HAWQ-V3 README (line 61) links to https://github.com/Zhen-Dong/BitPack but the code is NOT in this repo. The README describes its purpose:
  1338→
  1339→> Checkpoints in [model zoo](model_zoo.md) are saved in floating point precision. To shrink the memory size, [BitPack](https://github.com/Zhen-Dong/BitPack) can be applied on `weight_integer` tensors, or directly on quantized_checkpoint.pth.tar file.
  1340→
  1341→So BitPack is a **post-training checkpoint compressor** — takes the `weight_integer` buffer (saved by `quant_train.py` line 667) and bit-packs the INT4/INT8 integers into a compact binary format for deployment. It's NOT used during training or for ILP.
  1342→
  1343→**Repo-internal alternative**: `tvm_benchmark/hawq_utils_resnet50.py` lines 21-42 has `pack_int32_to_int4` and `unpack_int4_to_int32` — packs 8 int4 values per int32 (NHWC layout, TVM-specific):
  1344→
  1345→```python
  1346→def pack_int32_to_int4(a_int32):
  1347→    """Pack 8 int4 values into one int32. Layout: NHWC, big-endian within int32."""
  1348→    I, J, K, L = a_int32.shape
  1349→    a_int4 = np.zeros(shape=(I, J, K, L // 8), dtype=np.int32)
  1350→    for i in range(I):
  1351→        for j in range(J):
  1352→            for k in range(K):
  1353→                for l in range(L // 8):
  1354→                    for m in range(min(8, L-l*8)):
  1355→                        a_int4[i, j, k, l] |= ((a_int32[i, j, k, l*8+m] & 0xf) << ((7-m) * 4))
  1356→    return a_int4
  1357→```
  1358→
  1359→**For SHMQ-Ultimate**: BitPack is external and CNN/TVM-specific. **We will use AutoGPTQ's packing instead** (the `pack_int4` Marlin-compatible packer, already used by SliM-LLM). No code to extract from HAWQ-V3 here.

  1361→## PyHessian
  1362→
  1363→**Status**: PyHessian source code is **NOT in the HAWQ-V3 repo** — only the precomputed `Hutchinson_trace` arrays are pasted into `ILP.ipynb` (Cell 4 for ResNet18, Cell 17 for ResNet50). No import, no call, no helper.
  1364→
  1365→**How the trace was used in HAWQ-V3 (inferred from notebook)**:
  1366→1. Authors ran PyHessian OFFLINE (separate script, not in repo) on the pre-trained fp32 model.
  1367→2. For each weight matrix `W_l`, they computed `Hutchinson_trace_l = trace(H_l) / num_params_l` — i.e. **per-parameter-normalized** Hessian trace (this normalization is critical because deeper layers have more params and unnormalized trace would be biased toward them).
  1368→3. They pasted the resulting 19-element (ResNet18) / 52-element (ResNet50) numpy arrays into the notebook.
  1369→4. The ILP uses these as the per-layer sensitivity weight: `sensitivity_diff = Hutchinson_trace * (delta_w_8_sq - delta_w_4_sq)`.
  1370→
  1371→**For SHMQ-Ultimate**: we have the **`pyhessian`** package installed via pip (location: `/home/z/.venv/lib/python3.12/site-packages/pyhessian/`). We will use it DIRECTLY (no need to vendor HAWQ-V3's code — there isn't any). The relevant API:
  1372→
  1373→```python
  1374→from pyhessian import hessian
  1375→
  1376→# Wrap model + criterion + calibration data
  1377→hessian_comp = hessian(model, criterion, data=(inputs, targets), cuda=False)
  1378→
  1379→# Compute Hutchinson trace (maxIter=100 default, tol=1e-3)
  1380→trace_mean, trace_norm = hessian_comp.trace(maxIter=100, tol=0.001)
  1381→# trace_mean = average trace over the iterations
  1382→# trace_norm = trace of normalized Hessian (different normalization)
  1383→```
  1384→
  1385→**Caveats for LLMs** (vs CNNs):
  1386→1. **Per-layer, not per-model**: HAWQ-V3 computes trace per layer (per weight matrix). PyHessian's default `trace()` gives the trace of the FULL Hessian over all params. To get per-layer traces, we need to either:
  1387→   - Loop: temporarily set `requires_grad=False` on all params except layer `l`, compute trace, divide by `num_params_l`, restore. (Slow but works.)
  1388→   - OR use `hessian_vector_product` and diagonal estimation — `pyhessian.hessian.dataloader_hv_product` — to compute the diagonal of the Hessian block for each layer in one pass. (Faster but more code.)
  1389→2. **Calibration data**: SHMQ spec uses 128 samples × 2048 tokens from WikiText2. We need to batch these through the model with a loss (e.g. next-token-prediction CE) and pass to `hessian()`.
  1390→3. **Memory**: full Hessian is infeasible (params² entries), but Hutchinson trace only needs HVPs (Hessian-vector products) which are O(params) memory. Should fit on a single GPU for 7B.
  1391→4. **CPU-only caveat**: our sandbox has NO GPU. We can develop/test on tiny models (e.g. a single transformer block) but the actual 7B trace computation must run on the user's GPU. Document this limitation.
  1392→5. **Alternative (Fisher)**: per SHMQ paper Appendix A, Fisher approximation `H ≈ F = (1/|D|) Σ g g^T` is preferred for **inter-layer** sensitivity because it's "agnostic to hidden states magnitude" (Eq. 7). Fisher is simpler to compute (just need per-sample gradients). **Default for SHMQ-Ultimate: use Fisher for inter-layer (per SHMQ paper), use PyHessian only as an ablation/comparison.**
  1393→
  1394→**Concrete plan for SHMQ-Ultimate sensitivity module** (to be built in Task 1.x):
  1395→- Default path: `compute_fisher_sensitivity(model, calib_loader)` → returns per-layer Fisher-based sensitivity (Eq. 7).
  1396→- Optional path: `compute_hessian_trace(model, calib_loader, method='pyhessian')` → returns per-layer normalized Hutchinson trace via `pyhessian.hessian.trace()`.
  1397→- Both feed into the same ILP solver (output: per-layer bit-widths).

  1462→## SignSGD Algorithm
  1463→- **File**: `auto_round/algorithms/quantization/sign_round/sign_sgd.py`
  1464→- **Class**: `SignSGD(Optimizer)` — extends `torch.optim.optimizer.Optimizer`
  1465→- **Critical update line (line 389)**:
  1466→  ```python
  1467→  param.add_(torch.sign(d_p), alpha=-lr)
  1468→  ```
  1469→- **Algorithm description**:
  1470→  1. Compute gradient `g_t = ∇θ f(θ_{t-1})` via autograd (loss is MSE between quantized and FP block output)
  1471→  2. (Optional) weight decay: `g_t = g_t + λ·θ_{t-1}` (default λ=0)
  1472→  3. (Optional) momentum: `b_t = μ·b_{t-1} + (1-τ)·g_t` (default μ=0, so disabled)
  1473→  4. (Optional) Nesterov: `g_t = g_t + μ·b_t`
  1474→  5. **Sign update**: `θ_t = θ_{t-1} - lr · sign(g_t)` — note `sign(g_t)`, NOT `g_t` itself
  1475→  6. The LR schedule decays `lr` linearly: `lr_t = lr_0 · (1 - t/iters)`
  1476→  7. Repeat for `iters` (200) iterations
  1477→  8. After all iterations: restore the best-MSE checkpoint (V values that gave lowest block-output MSE)
  1478→  9. **Bake V into weight** (see next section)
  1479→- **Key code (SignSGD core)**:
  1480→  ```python
  1481→  class SignSGD(Optimizer):
  1482→      def __init__(self, params, lr=required, momentum=0, dampening=0,
  1483→                   weight_decay=0, nesterov=False, *, maximize=False,
  1484→                   foreach=None, differentiable=False):
  1485→          # Standard SGD defaults; nesterov requires momentum > 0
  1486→          defaults = dict(lr=lr, momentum=momentum, ...)
  1487→          super().__init__(params, defaults)
  1488→
  1489→      @_use_grad_for_differentiable
  1490→      def step(self, closure=None):
  1491→          for group in self.param_groups:
  1492→              params_with_grad, d_p_list, momentum_buffer_list = [], [], []
  1493→              for p in group["params"]:
  1494→                  if p.grad is not None:
  1495→                      params_with_grad.append(p)
  1496→                      d_p_list.append(p.grad)
  1497→                      # ... momentum buffer bookkeeping
  1498→              sgd(params_with_grad, d_p_list, momentum_buffer_list,
  1499→                  weight_decay=group["weight_decay"], momentum=group["momentum"],
  1500→                  lr=group["lr"], dampening=group["dampening"],
  1501→                  nesterov=group["nesterov"], maximize=group["maximize"],
  1502→                  has_sparse_grad=has_sparse_grad, foreach=group["foreach"])
  1503→
  1504→  def _single_tensor_sgd(params, d_p_list, momentum_buffer_list, *,
  1505→                         weight_decay, momentum, lr, dampening, nesterov,
  1506→                         maximize, has_sparse_grad):
  1507→      for i, param in enumerate(params):
  1508→          d_p = d_p_list[i] if not maximize else -d_p_list[i]
  1509→          if weight_decay != 0:
  1510→              d_p = d_p.add(param, alpha=weight_decay)
  1511→          if momentum != 0:
  1512→              buf = momentum_buffer_list[i]
  1513→              if buf is None:
  1514→                  buf = torch.clone(d_p).detach()
  1515→                  momentum_buffer_list[i] = buf
  1516→              else:
  1517→                  buf.mul_(momentum).add_(d_p, alpha=1 - dampening)
  1518→              if nesterov:
  1519→                  d_p = d_p.add(buf, alpha=momentum)
  1520→              else:
  1521→                  d_p = buf
  1522→          # ===== THE SIGN TRICK =====
  1523→          param.add_(torch.sign(d_p), alpha=-lr)   # θ ← θ − lr · sign(g)
  1524→  ```
  1525→- **Per-block training loop (from `quantize_block`)**:
  1526→  ```python
  1527→  # Collect trainable params: round_params = [V per layer], minmax_params = [min_scale, max_scale]
  1528→  optimizer = SignSGD([{"params": round_params},
  1529→                       {"params": minmax_params, "lr": minmax_lr}],
  1530→                      lr=lr, weight_decay=0, momentum=self.momentum)
  1531→  lr_schedule = torch.optim.lr_scheduler.LinearLR(
  1532→      optimizer, start_factor=1.0, end_factor=0.0, total_iters=self.iters)
  1533→  mse_loss = torch.nn.MSELoss(reduction="mean")
  1534→  index_sampler = IndexSampler(nsamples, global_batch_size)  # cyclic shuffled sampler
  1535→
  1536→  for i in range(self.iters):
  1537→      total_loss = 0
  1538→      global_indices = index_sampler.next_batch()
  1539→      for batch_start in range(0, len(global_indices), batch_size):
  1540→          indices = global_indices[batch_start:batch_start+batch_size]
  1541→          ref_output = torch.cat([fp_outputs[i] for i in indices], dim=0).to(loss_device)
  1542→          pred_output = block_fwd.forward(block, active_inputs, input_others, indices, ...)
  1543→          # MSE between quantized block output and FP reference output:
  1544→          loss = mse_loss(pred_output.float(), ref_output.float())
  1545→          total_loss += loss.item() / num_elm
  1546→          scale_loss = loss * 1000  # numerical stability multiplier
  1547→          scale_loss.backward()    # populate V.grad via round_ste STE
  1548→      # Track best-MSE checkpoint
  1549→      if total_loss < best_loss:
  1550→          best_loss = total_loss
  1551→          if not self.not_use_best_mse:
  1552→              best_params = collect_best_params(block, cache_device)
  1553→              last_best_iter = i
  1554→      # SignSGD step + LR schedule step
  1555→      optimizer.step(); optimizer.zero_grad(); lr_schedule.step()
  1556→  # Restore best params and bake into weights
  1557→  with torch.no_grad():
  1558→      unwrapper_block(block, best_params)
  1559→  ```

  1561→## V Initialization and Update
  1562→- **V shape**: Same as the group-reshaped weight tensor. For a `Linear` weight of shape `(cout, cin)` with `group_size=128`, V has shape `(-1, 128)` (i.e. `(cout * ceil(cin/128), 128)`). Computed via `reshape_pad_tensor_by_group_size(orig_weight.data, group_size)` in `WrapperLinear._init_tuning_params_and_quant_func`.
  1563→- **V init**: `torch.zeros(shape, dtype=torch.float32, requires_grad=True)` (from `_init_params("value", torch.float32, weight_reshape.shape, 0, ...)` — `value=0` and `torch.ones(shape)*0`).
  1564→- **V attribute name**: `self.value` on `WrapperLinear`; stored in `self.params["value"]`. (Note: the WrapperLayerNorm/WrapperLlamaNorm variants use `self.v` instead.)
  1565→- **V update rule**: `V ← V − lr · sign(∂L/∂V)` (SignSGD). The gradient flows from MSE loss → block output → wrapper.forward → `_qdq_weight(value=self.value, ...)` → `weight_quant_func(weight, v=value, ...)` → `round_ste(w/scale + v)`.
  1566→- **V projection/clamping**: **NONE in code.** V is a free float32 parameter, never explicitly clamped to [-1, 1]. The implicit "tempering" is:
  1567→  - SignSGD step size is always `±lr` per element (lr decays linearly to 0).
  1568→  - For 200 iters with `lr=5e-3`, max accumulated drift ≈ `200 × 5e-3 = 1.0`. So V stays roughly in `[-1, 1]` empirically — matching the paper's claim but without explicit clamping.
  1569→  - The formula `round(w/scale + V)` is invariant to V's magnitude — V only shifts which integer `w/scale` rounds to (effectively a per-element "round up vs round down" decision).
  1570→
  1571→## Baking V into Weights (ZERO INFERENCE OVERHEAD)
  1572→- **File**: `auto_round/wrapper.py`
  1573→- **Function**: `WrapperLinear.unwrapper(self, best_params)` (called from `unwrapper_block(block, best_params)`)
  1574→- **Exact formula** (symmetric case, from `quant_tensor_sym` in `data_type/int.py`):
  1575→  ```
  1576→  Q(w) = scale * clamp( round(w / scale + V*),  -maxq,  maxq-1 )
  1577→  ```
  1578→  where:
  1579→  - `maxq = 2^(bits-1)` (e.g. `8` for 4-bit, `128` for 8-bit)
  1580→  - `V*` = optimized V from SignSGD (best-MSE checkpoint)
  1581→  - `scale = max_v / maxq` where `max_v = max(|wmin * min_scale|, |wmax * max_scale|)` per group, clamped to `±q_scale_thresh`
  1582→  - `round` is the standard round-half-to-even (NOT `round_ste` — STE is only for backprop; at baking time we use the real `torch.round` via `round_ste`'s forward branch `(x.round() - x).detach() + x` which equals `x.round()` in forward)
  1583→- **Key code (`WrapperLinear.unwrapper`)**:
  1584→  ```python
  1585→  def unwrapper(self, best_params):
  1586→      best_params = best_params or {}
  1587→      v = best_params.get("value", torch.tensor(0.0)).to(self.device)
  1588→      min_scale = best_params.get("min_scale", torch.tensor(1.0)).to(self.device)
  1589→      max_scale = best_params.get("max_scale", torch.tensor(1.0)).to(self.device)
  1590→
  1591→      # === BAKE: compute final qdq weight using optimized V ===
  1592→      qdq_weight, scale, zp = self._qdq_weight(v, min_scale, max_scale)
  1593→      # === OVERWRITE the original weight with the baked qdq weight ===
  1594→      self.orig_layer.weight.data.copy_(qdq_weight)   # <-- THIS IS THE BAKING
  1595→      self.orig_layer.weight.grad = None
  1596→
  1597→      # Store scale/zp as layer attributes (for export to GPTQ/AWQ/AutoRound formats)
  1598→      self.orig_layer.scale = scale.reshape(shape[0], -1).to("cpu")
  1599→      self.orig_layer.zp = zp.reshape(shape[0], -1).to("cpu")  # zp = maxq for sym
  1600→      ...
  1601→      return self.orig_layer   # wrapper is replaced by the original layer in the model
  1602→  ```
  1603→- **`_qdq_weight` (the actual quant function call)**:
  1604→  ```python
  1605→  def _qdq_weight(self, value, min_scale, max_scale):
  1606→      min_scale.data.clamp_(0.0, 1.0)   # constrain min/max tuning coefficients
  1607→      max_scale.data.clamp_(0.0, 1.0)
  1608→      weight = self.orig_layer.weight    # may transpose for Conv1D
  1609→      weight_q, scale, zp = self.weight_quant_func(
  1610→          weight.to(self.device),
  1611→          bits=self.orig_layer.bits,
  1612→          group_size=self.orig_layer.group_size,
  1613→          v=value,                       # <-- V (the rounding offset)
  1614→          min_scale=min_scale,           # <-- per-group min tuning coefficient
  1615→          max_scale=max_scale,           # <-- per-group max tuning coefficient
  1616→          scale_dtype=self.orig_layer.scale_dtype,
  1617→          tensor_min=self.weight_min,    # pre-computed per-group min (clip bound)
  1618→          tensor_max=self.weight_max,
  1619→          data_type=self.data_type,
  1620→          q_scale_thresh=self.q_scale_thresh,
  1621→          ...)
  1622→      return weight_q, scale, zp
  1623→  ```
  1624→- **Quant function (symmetric, `data_type/int.py` `quant_tensor_sym`)**:
  1625→  ```python
  1626→  @register_dtype("int_sym")
  1627→  def quant_tensor_sym(tensor, bits=4, group_size=-1, v=0, min_scale=1.0, max_scale=1.0,
  1628→                       scale_dtype=torch.float16, tensor_min=None, tensor_max=None,
  1629→                       q_scale_thresh=1e-5, init_scale=None, **kwargs):
  1630→      tensor, orig_shape, pad_len = reshape_pad_tensor_by_group_size(tensor, group_size)
  1631→      maxq = int(2.0 ** (bits - 1))                              # 8 for 4-bit
  1632→      # Compute per-group scale from tensor_min/tensor_max (or compute on-the-fly)
  1633→      wmin_tmp = tensor_min if tensor_min is not None else torch.clamp(tensor.min(-1)[0], max=0)
  1634→      wmax_tmp = tensor_max if tensor_max is not None else torch.clamp(tensor.max(-1)[0], min=0)
  1635→      wmin_abs = -(wmin_tmp * min_scale)                         # apply tunable coefficient
  1636→      wmax_abs =  wmax_tmp * max_scale
  1637→      max_v = (2 * (wmax_abs < wmin_abs).int() - 1) * torch.max(wmax_abs, wmin_abs)
  1638→      scale = (max_v / maxq).to(scale_dtype)                     # per-group scale
  1639→      scale = torch.where(scale < 0,
  1640→                          torch.clamp(scale, max=-q_scale_thresh),
  1641→                          torch.clamp(scale, min=q_scale_thresh))
  1642→      scale = scale.unsqueeze(dim=-1)                            # broadcast over group
  1643→      # ===== THE ROUNDING WITH V =====
  1644→      int_w = round_ste(tensor / scale + v)                      # forward = round(w/scale + V)
  1645→      q = torch.clamp(int_w, -maxq, maxq - 1)                    # clamp to valid range
  1646→      qdq_result = (scale * q).to(tensor.dtype)                  # dequantize back to FP
  1647→      qdq_result = revert_tensor_by_pad(qdq_result, orig_shape, pad_len)
  1648→      return qdq_result, scale, maxq
  1649→  ```
  1650→- **`round_ste` (Straight-Through Estimator)**:
  1651→  ```python
  1652→  def round_ste(x: torch.Tensor):
  1653→      # Forward:  round(x)
  1654→      # Backward: identity (gradient flows as if round() weren't there)
  1655→      return (x.round() - x).detach() + x
  1656→  ```
  1657→- **Result**: After baking, the original `nn.Linear` weight has been replaced with `Q(w)` — the V parameter is **discarded**. Inference uses the standard `F.linear(x, weight_q)` with no extra overhead. The scale and zero-point are stored on `orig_layer.scale`/`orig_layer.zp` for downstream kernel packing (GPTQ/AWQ/Marlin).

  1738→## Calibration API
  1739→- **File**: `auto_round/calibration/llm.py`
  1740→- **Class**: `LLMCalibrator(Calibrator)`, registered as `"llm"`
  1741→- **Constructor**: `__init__(self, compressor)` — pulls `model`, `tokenizer`, `dataset`, `seed`, `batch_size`, `seqlen` from compressor
  1742→- **How activations are captured**:
  1743→  1. `calibration(block_names, nsamples, layer_names, last_cache_name)` → calls `cache_inter_data(...)`
  1744→  2. `cache_inter_data` calls `replace_forward_with_hooks()`:
  1745→     - For each block in `block_names`: monkey-patches `block.forward = partial(self._get_block_forward_func(name), m)`, saving the original as `m.orig_forward`
  1746→     - For each layer in `layer_names`: registers `make_layer_cache_hook(name)` as a forward hook
  1747→  3. `calib(nsamples, bs)`:
  1748→     - Loads calibration data via `get_dataloader(tokenizer, seqlen, dataset, seed, bs, nsamples)`
  1749→     - For each batch: `self.model(input_ids, attention_mask=..., use_cache=False)` runs forward
  1750→     - The patched block forward `forward_capture(m, hidden_states, *pos, **kwargs)`:
  1751→       - First call: `self.inputs[name] = {}` then for each kwarg tensor, `torch.split(tensor, 1, dim=batch_dim)` and append each sample to `self.inputs[name][key]` (list of `[1, seq, hidden]` tensors on CPU)
  1752→       - Subsequent calls: extend the lists
  1753→       - After caching: if `name == last_cache_name` → raise `NotImplementedError` to short-circuit forward (skip remaining blocks for speed)
  1754→       - Otherwise: `return m.orig_forward(hidden_states, **kwargs)` to continue normally
  1755→  4. Returns `self.inputs` = `{block_name: {"hidden_states": [tensor_0, ..., tensor_n], "attention_mask": [...], "position_ids": [...]}, layer_name: [tensor_0, ...], "input_ids": [tensor_0, ...]}`
  1756→- **Key detail**: each block sees the FP output of the previous FP block (not quantized). When `enable_quanted_input=True` (default), the quantizer separately runs the block forward through the wrapper to get the quantized block output, then feeds that as input to the next block — this is done in the SignRound quantizer's `block_fwd.forward(...)` call, not the calibrator.

  1758→## AutoRound Wrapper (`wrapper.py`)
  1759→- **Class**: `WrapperLinear(torch.nn.Module)` — wraps `nn.Linear` / `Conv1D` / `LinearAllreduce`
  1760→- **Trainable params stored in `self.params` dict**:
  1761→  - `"value"`: the V tensor (rounding offset), shape = grouped weight shape, init=0
  1762→  - `"min_scale"`: per-group min coefficient, shape = `get_scale_shape(weight, group_size)`, init=1.0
  1763→  - `"max_scale"`: per-group max coefficient, same shape, init=1.0
  1764→  - (optional) `"act_min_scale"`, `"act_max_scale"`, `"bias_v"` if those features are enabled
  1765→- **Forward pass** (`WrapperLinear.forward(x)`):
  1766→  ```python
  1767→  def forward(self, x):
  1768→      x = x.to(self.device)
  1769→      weight_q, *_ = self._qdq_weight(self.value, self.min_scale, self.max_scale)
  1770→      if self.enable_act_quant:
  1771→          x, _, _ = self._qdq_act(x, act_max_scale=..., act_min_scale=..., act_max=...)
  1772→      bias = self.orig_layer.bias
  1773→      if self.enable_norm_bias_tuning:
  1774→          bias, _, _ = self._qdq_bias(bias, self.bias_v)
  1775→      output = self.orig_forward(x, weight_q, bias).to(self.output_device)  # F.linear(x, weight_q, bias)
  1776→      return output
  1777→  ```
  1778→- **`wrapper_block(block, enable_minmax_tuning, enable_norm_bias_tuning, ...)`**: iterates `block.named_modules()`, replaces each `nn.Linear`/`Conv1D` in `SUPPORTED_LAYER_TYPES` with `WrapperLinear(m, ...)` via `set_module(block, name, wrapper)`. Returns `(quantized_layer_names, unquantized_layer_names)`.
  1779→- **`unwrapper_block(block, best_params)`**: iterates wrapped modules, calls `m.unwrapper(best_params[n])` which bakes V+min_scale+max_scale into `orig_layer.weight.data`, then replaces wrapper with `orig_layer`. After this, the block contains plain `nn.Linear` modules with already-quantized weights — **zero inference overhead**.
  1780→- **`collect_best_params(block, cache_device)`**: snapshots `m.params[key].data` for every wrapped layer — used to track the best-MSE checkpoint during SignSGD iterations.

  1782→## Hyperparameter Verification (vs AutoRound paper)
  1783→- **200 steps** ✓ `iters=200` (default)
  1784→- **LR 1e-3 to 5e-3** ✓ `lr=None` resolves to `1.0/iters = 5e-3` for `iters=200` (in `SignRoundConfig.finalize_scheme()`); the `auto-round-light` recipe uses `lr=5e-3` explicitly with `iters=50`
  1785→- **LR decay (cosine or linear)** ✓ default `LinearLR(start_factor=1.0, end_factor=0.0, total_iters=iters)` — **linear decay to 0** (cosine also supported by passing a custom `lr_scheduler`)
  1786→- **Tempering / V projection to [-1, 1]** ⚠ **NOT explicitly clamped in code**. V is a free `torch.float32` parameter. The implicit tempering comes from:
  1787→  - SignSGD step size `±lr` per element per iteration
  1788→  - lr decays linearly from `5e-3` to `0` over 200 steps
  1789→  - Total accumulated drift ≤ `sum_t lr_t ≈ 200 × 5e-3 / 2 = 0.5` per element
  1790→  - So V stays roughly within `[-0.5, 0.5]` empirically — well within `[-1, 1]`. The paper's "tempering to [-1, 1]" is achieved implicitly via the lr schedule, not via explicit clamping. (This is a key implementation detail for SHMQ-Ultimate to replicate.)
  1791→- **MSE loss between quantized block output and FP block output** ✓ `torch.nn.MSELoss(reduction="mean")` between `pred_output` (block with wrapped Linear) and `ref_output` (FP reference)
  1792→- **Best-MSE checkpoint** ✓ `collect_best_params(block, cache_device)` snapshots V every iteration when `total_loss < best_loss`; restored via `unwrapper_block(block, best_params)` at the end
  1793→- **Loss scaling** ✓ `loss * 1000` before `.backward()` (`_scale_loss_and_backward`) — improves gradient numerical stability on CPU/AMP

  1795→## Integration Notes for SHMQ-Ultimate
  1796→- **Order in pipeline**: AutoRound SignRound should run as **Step 6 of our SHMQ-Ultimate pipeline**, AFTER:
  1797→  1. SmoothQuant (activation outlier migration)
  1798→  2. SHMQ permutation (decoupled sort by sensitivity)
  1799→  3. Permutation fusion into RMSNorm/activation
  1800→  4. HAWQ-V3 ILP bit allocation (inter-layer)
  1801→  5. SliM-LLM OBS (intra-layer per-element sensitivity, used to drive TopK split)
  1802→  6. **AutoRound SignSGD rounding** ← THIS STEP
  1803→  7. Final packing into GPTQ/AWQ/Marlin format
  1804→- **Per-block application**: AutoRound natively processes one transformer block at a time. The `quantize_block(block, fp_inputs, fp_outputs, ...)` entry point is what we should call. For SHMQ-Ultimate, we should:
  1805→  - Run the SHMQ-permuted, SmoothQuant-scaled model through AutoRound's calibrator to capture per-block FP inputs (use `LLMCalibrator` directly, or replicate its hook logic in our pipeline).
  1806→  - For each block: instantiate `WrapperLinear` on each `nn.Linear` in the block, run SignSGD for 200 iterations with `lr=5e-3` and linear LR decay, then call `unwrapper_block` to bake V.
  1807→- **Mixed-bit (W4.8A8) support**: AutoRound's `layer_config` dict supports per-layer overrides — we can pass the ILP bit allocation as `layer_config = {"model.layers.5.self_attn.q_proj": {"bits": 8, "group_size": 128}, ...}`. AutoRound will then apply SignRound with the assigned bits per layer.
  1808→- **Hyperparameters to use**:
  1809→  - `iters=200`, `lr=5e-3` (or `None` → auto), `momentum=0.0`
  1810→  - `lr_scheduler=LinearLR(start_factor=1.0, end_factor=0.0, total_iters=200)`
  1811→  - `enable_minmax_tuning=True` (also tune per-group min/max scales)
  1812→  - `enable_quanted_input=True` (cascaded: feed quantized block output to next block — matches GPTQ-style error accumulation)
  1813→  - `not_use_best_mse=False` (restore best checkpoint)
  1814→  - `gradient_accumulate_steps=1`, `batch_size=8` (or `bs=1, gradient_accumulate_steps=8` for low VRAM)
  1815→  - `nsamples=128, seqlen=2048` (matches SHMQ paper)
  1816→  - `group_size=128` (matches SHMQ paper)
  1817→  - `sym=True` (symmetric — matches SHMQ paper)
  1818→- **Constraints**:
  1819→  - **V MUST be baked into weights before saving** — call `unwrapper_block` (or instantiate `WrapperLinear` then call `.unwrapper(best_params)`) before exporting. The baked weight is `Q(w) = scale * clamp(round(w/scale + V*), -maxq, maxq-1)`.
  1820→  - After baking, store `scale` (per-group) and `zp` (= `maxq` for sym, or computed for asym) on the layer for downstream GPTQ/AWQ/Marlin packing.
  1821→  - The wrapper's `weight_quant_func` is selected by `data_type` (`"int_sym"` for sym INT, `"int_asym"` for asym). For SHMQ W4.8A8 use `data_type="int"`, `sym=True`.
  1822→  - **CPU-only caveat**: Our environment has NO GPU. SignRound on CPU is feasible for small models (Qwen2.5-0.5B / 1.5B) but slow for 7B. Set `device="cpu"` and `enable_torch_compile=False` (compile is CUDA-only). Reduce `nsamples` to 32 and `seqlen` to 512 for CPU smoke tests.

  1829→- **Minimal SignRound recipe for SHMQ-Ultimate (pseudo-code)**:
  1830→  ```python
  1831→  import torch
  1832→  from auto_round.wrapper import WrapperLinear, wrapper_block, unwrapper_block
  1833→  from auto_round.algorithms.quantization.sign_round.sign_sgd import SignSGD
  1834→  from auto_round.compressors.utils import collect_best_params, IndexSampler
  1835→
  1836→  def signround_block(block, fp_inputs, fp_outputs, input_others, *,
  1837→                      bits=4, group_size=128, sym=True,
  1838→                      iters=200, lr=5e-3, batch_size=8, device="cpu"):
  1839→      # 1. Wrap all nn.Linear in the block
  1840→      quantized_names, _ = wrapper_block(block, enable_minmax_tuning=True,
  1841→                                          enable_norm_bias_tuning=False,
  1842→                                          enable_torch_compile=False, device=device)
  1843→      # 2. Collect trainable params
  1844→      round_params, minmax_params = [], []
  1845→      for n, m in block.named_modules():
  1846→          if hasattr(m, "orig_layer"):
  1847→              for k in m.params:
  1848→                  if "min" in k or "max" in k: minmax_params.append(m.params[k])
  1849→                  else: round_params.append(m.params[k])
  1850→      # 3. SignSGD optimizer + linear LR decay
  1851→      optimizer = SignSGD([{"params": round_params},
  1852→                           {"params": minmax_params, "lr": lr}],
  1853→                          lr=lr, weight_decay=0, momentum=0.0)
  1854→      lr_schedule = torch.optim.lr_scheduler.LinearLR(
  1855→          optimizer, start_factor=1.0, end_factor=0.0, total_iters=iters)
  1856→      mse = torch.nn.MSELoss(reduction="mean")
  1857→      nsamples = len(fp_inputs)
  1858→      sampler = IndexSampler(nsamples, min(nsamples, batch_size))
  1859→      best_loss, best_params = float("inf"), {}
  1860→      # 4. Training loop
  1861→      for i in range(iters):
  1862→          total_loss = 0.0
  1863→          for idx in sampler.next_batch():
  1864→              ref = fp_outputs[idx].to(device)
  1865→              pred = block(fp_inputs[idx].to(device), **input_others)  # wrapper applies V
  1866→              loss = mse(pred.float(), ref.float())
  1867→              total_loss += loss.item()
  1868→              (loss * 1000).backward()
  1869→          if total_loss < best_loss:
  1870→              best_loss = total_loss
  1871→              best_params = collect_best_params(block, "cpu")
  1872→          optimizer.step(); optimizer.zero_grad(); lr_schedule.step()
  1873→      # 5. BAKE V into weights — ZERO INFERENCE OVERHEAD
  1874→      with torch.no_grad():
  1875→          unwrapper_block(block, best_params)
  1876→      return block
  1877→  ```

  1953→### Key Design Decisions
  1954→
  1955→1. **Fisher as default inter-layer Hessian** (per SHMQ paper App. A.2 ablation).
  1956→   PyHessian trace available as alternative (config.inter_layer_hessian="pyhessian").
  1957→
  1958→2. **ILP with 2 levels {4, 8}** (per user's plan, not the proportion mapping from Eq. 8).
  1959→   ILP is mathematically optimal and HAWQ-V3 already has the PULP code.
  1960→
  1961→3. **Parallel constraint via equality in ILP** (q/k/v same bits; up/gate same bits).
  1962→   This is needed for permutation fusion compatibility.
  1963→
  1964→4. **Decoupled permutation** strictly per SHMQ §3.2.3:
  1965→   - Sort by sensitivity → partition → sort by magnitude within each cluster
  1966→   - Group-size aligned (128) for tensor cores
  1967→
  1968→5. **PermutedRMSNorm** correctly gathers x by perm AND uses permuted weight.
  1969→   (Earlier version had a bug: only permuted weight, not input. Fixed after testing.)
  1970→
  1971→6. **AutoRound applied per-block** (200 iters per transformer block, SignSGD).
  1972→   V is initialized to zeros, baked into weights after optimization.
  1973→
  1974→7. **SQC calibration** runs as grid search over scale multiplier ∈ [0.9, 1.1].
  1975→   4-bit layers get SQC; 8-bit layers just use RTN (already near-lossless).
